# UI shell (planned)

A GPU-accelerated 10-foot UI built on **Lightning 3 / Blits** (WebGL). Lightning
is chosen over DOM/React because it renders on a single canvas and performs well
on constrained MediaTek/Novatek SoCs where DOM-heavy UIs drop frames.

This package is a scaffold placeholder in v0.1. See `docs/DEVELOPMENT_PLAN.md`
(Phase 3) for the implementation plan.
